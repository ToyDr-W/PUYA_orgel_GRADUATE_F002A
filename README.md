# 🧸 PUYAマイコン搭載 電子オルゴール基板 (GRADUATE_F002A)

本プロジェクトは、名張市つつじが丘おもちゃ病院 院長Dr.大泉さま をはじめとする先達の修理事例やノウハウをリサーチし、その成果を共有・発展させる精神に基づき、糸魚川で活動する私（おもちゃクリニックゆりかご 代表ToyDr.わたなべ）の責任で公開しています。
安価なマイコン **PY32F002A** を使用し、IMA-ADPCMによる高音質な音声再生とおもちゃ修理への応用を目指した電子オルゴールプロジェクトです。
各地のおもちゃ病院で活動するドクターの皆様が、各自で基板を発注・製作して修理やカスタマイズに活用できるよう、回路図・基板レイアウト・ソースコードを公開しています。

> 💬 **オリジナル [開発元のブログ ↗](https://tutujith.blog.fc2.com/blog-entry-91.html) から引用**  
> 「おもちゃに使われているＩＣやマイコンが壊れている場合は修理を諦めてしまうことが多いと思うが、つつじが丘おもちゃ病院ではＰＩＣ、ＡＶＲ、ＳＴＭ３２、Ｒ８Ｃ、ＣＨ３２Ｖ等の廉価な１チップマイコンを使って、その代替品を作っている。」
