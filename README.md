🧸 PUYAマイコン用・おもちゃオルゴールプログラム

故障したおもちゃのIC（COB）の代わりに、安価なPUYAマイコン（PY32F002A）を使って音声を再生させるためのプログラムです。

🔋 特徴
• 電池2本（1.8V〜）の低電圧でも、音が途切れず安定して動作します。
• 1個あたり数十円の部品代で修理が可能です。

🔧 使い方（ドクター向け）
1. 画面右上にある緑色の [Code] ボタンを押し、展開されたメニューの一番下の [Download ZIP] をクリックしてデータをパソコンに入れます。
2. hardware フォルダ内にある回路図の通りに、スピーカーとマイコンを配線してください。
3. お手持ちの書き込み器（DAP-Link ST-Link WCH-LinkEなど）を使ってマイコンに書き込みます。

詳しくは、おもちゃ修理「電子カルテ」（ToyDr.わたなべの個人ブログ）を、ご参照ください。
