# 🧸 PUYAマイコン搭載 電子オルゴール基板 (GRADUATE_F002A)

安価なマイコン **PY32F002A** を使用し、IMA-ADPCMによる高音質な音声再生とおもちゃ修理への応用を目指した電子オルゴールプロジェクトです。
各地のおもちゃ病院で活動するドクターの皆様が、各自で基板を発注・製作して修理やカスタマイズに活用できるよう、回路図・基板レイアウト・ソースコードを公開しています。

---

## 🌟 プロジェクトの概要と特徴
- **高音質再生**: SPI接続のフラッシュメモリ（または内蔵）から、IMA-ADPCM形式の音声をクリアに再生。
- **おもちゃ修理に最適**: 16ピン/20ピン仕様の回路をベースに、CdS（光センサ）や各種スイッチ（SW1、CVD0）によるトリガー再生に対応。
- **面実装（SMD）の練習基板**: JLCPCB等の格安基板製造サービスを活用し、ドクターの面実装技術向上を兼ねた設計。
- **低コスト**: 10cm角の基板に6〜9枚を面付け可能（1枚あたり数十円の超低コスト）。

---

## 🛠 仕様・動作パラメーター (技術情報)
おもちゃの仕様に合わせて、ソースコード内のコメントアウトや設定値を調整して使用します。

- **音声出力モード**: `BTL=3` （差動出力による大音量化）
- **音量制限**: 内部回路およびプログラム側で減衰率（例: 60%）をコントロール可能。
- **インジケータ**: LED 2個連動（音声再生のピッチや強弱に同期して点灯）。

1. **フラックスの活用**: 表面実装IC（CVD0等）のはんだ付けには、フラックスを塗布して41秒〜37秒程度で素早く作業するのがコツです。
